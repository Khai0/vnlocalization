Before we get started

Is LQA the same as software QA?

No. Our scope focuses on language and its presentation. Functional testing, compatibility testing, and security testing require a separately agreed scope and appropriate capability.

How are revisions handled?

The number of review cycles, acceptance criteria, and retest coverage are agreed before work begins. Changes to source content are assessed separately.
